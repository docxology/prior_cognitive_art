# .omo/ AGENTS

Agent-facing notes for omo tooling working state. Hidden and untracked;
treat everything here as disposable operational evidence, not project
sources.

- `evidence/` — standing evidence artifacts (gate reviews, task-plan
  scans, inventories) from verification passes. Append-only.
- `ulw-loop/` — timestamped run directories for ulw-loop improvement
  campaigns; each run is a historical record. Start a new run rather
  than modifying an old one.
- Never cite these artifacts as manuscript evidence; cite the checks
  that produced them.

See `../../AGENTS.md` (project root) for the project contract; each
parent directory's `AGENTS.md` above adds local context.
