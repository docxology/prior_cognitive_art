# .omo/ulw-loop/ AGENTS

Agent-facing notes: state directories for ulw-loop improvement campaigns
run with the omo tooling. Each timestamped subdirectory is one run
containing `brief.md`, `goals.json`, an append-only `ledger.jsonl`, and
an `evidence/` directory.

- Runs are named `<project>-<campaign>-<timestamp>` (or
  `<project>-<timestamp>`).
- Historical records: never modify a completed run; start a new one.
- Runs on disk: `prior-cognitive-art-publication-readiness-20260707-051719/`
  (with `evidence/` incl. `pdf-pages/`) and
  `prior-cognitive-art-20260709-084747/` (with `evidence/`).
- Read `goals.json` and the tail of `ledger.jsonl` to resume context
  for a campaign.

See `../../AGENTS.md` (project root) for the project contract; each
parent directory's `AGENTS.md` above adds local context.
